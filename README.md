# supply-chain-Dashboard
Route Optimization Dashboard Analysis
This Power BI supply chain analytics dashboard evaluates logistics efficiency and cost distribution across 100 SKUs, analyzing performance across key transportation modes, regional hubs, and shipping routes. Featuring a total shipping cost of $52,925 and 4,922 total units sold, the report tracks critical operational drivers including defect rates by product type (haircare, skincare, cosmetics) and route-wise expenditure across major Indian logistical hubs (Bangalore, Chennai, Delhi, Kolkata, Mumbai). By integrating multi-variable data across transport channels, supplier routes, and product categories, this project provides actionable supply chain insights to optimize route selection, reduce transportation overhead, and minimize defect occurrence.
